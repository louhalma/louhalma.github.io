# Lou Halma — Portfolio

Site statique gratuit, prêt pour GitHub Pages.

## Personnaliser
1. Ouvre `index.html`.
2. Remplace le `href="#"` du bouton LinkedIn par ton URL LinkedIn.
3. Si tu veux changer le texte de la section ME, modifie directement les paragraphes.
4. Les trois images sont dans `assets/`.

## Mettre en ligne gratuitement
- Crée un dépôt GitHub public nommé `louhalma.github.io` (ou utilise un autre nom de dépôt et active Pages).
- Envoie `index.html`, `style.css`, `script.js` et le dossier `assets`.
- Dans GitHub : Settings → Pages → Deploy from a branch → `main` → `/root`.
- Le site sera disponible sur l'adresse GitHub Pages de ton dépôt.
